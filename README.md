📚 Personal Study Planner

A simple and user-friendly Personal Study Planner designed to help students organize their study schedules, manage subjects, track progress, and build consistent study habits.

The project provides a structured way to plan daily and weekly study sessions while keeping track of academic goals and completed tasks.

✨ Features

📅 Create and manage daily study plans

📚 Organize subjects and topics

✅ Add, edit, and complete study tasks

⏰ Set study schedules and deadlines

📊 Track study progress

🎯 Set academic goals

🔥 Monitor study consistency

📝 Add notes and reminders

📈 View completed and pending tasks

💻 Simple and responsive user interface

🌙 Optional dark mode

💾 Store and manage study data

🎯 Project Objectives

The main objectives of the Personal Study Planner are:

Help students organize their study schedules.

Make it easier to manage multiple subjects.

Encourage consistent study habits.

Track completed and pending tasks.

Help students achieve their academic goals.

Reduce the difficulty of planning study sessions manually.
